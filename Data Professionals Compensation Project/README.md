# Data Professionals Compensation Analysis

## Overview

This project analyzes compensation trends among data professionals using Python and Pandas. 
The workflow involves importing raw survey data, performing extensive data cleaning and transformation, and 
conducting exploratory data analysis (EDA) to uncover salary trends across different data roles.

## Objectives

- Clean and standardize survey data.
- Handle missing values and inconsistent entries.
- Analyze salaries by role, experience, and seniority level.
- Explore compensation trends within the data profession.

## Technologies

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Concepts Covered

- Data Import
- Data Cleaning
- Data Transformation
- Missing Value Handling
- String Manipulation
- Feature Engineering
- Exploratory Data Analysis (EDA)
- Grouping and Aggregation

## Analysis Performed

- Standardized job roles and industries.
- Cleaned technology stack and salary data.
- Converted salary values into a consistent numeric format.
- Analyzed the number of respondents by role.
- Calculated average salaries by:
  - Role
  - Seniority Level
  - Years of Experience
- Compared compensation for Data Analysts, Data Engineers, and Data Scientists.
